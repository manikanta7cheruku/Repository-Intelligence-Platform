# Prompts

Copy-paste prompts that start or resume each phase in a new AI chat. Each prompt tells the assistant what was done before, what to read, what to build, which documents
and learning files to update, and the rules to follow.

| File | Use it when |
|---|---|
| [HANDOFF.md](HANDOFF.md) | Before starting Phase 2 or 3 in a new chat: exactly what to attach and what to say first |
| [phase-2-prompt.md](phase-2-prompt.md) | Start Phase 2 (web platform, UI and UX) |
| [phase-3-prompt.md](phase-3-prompt.md) | Start Phase 3 (hardening, GitHub Action, release) after Phase 2 |

Resume prompts for each phase are in the phase files (`docs/phases`). The academic documents prompt is at the end of `docs/phases/phase-3-hardening-release.md`.
