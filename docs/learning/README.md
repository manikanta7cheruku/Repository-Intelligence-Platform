# Learning guide

Purpose: so that you can explain every part of this project, why it exists and why it was built this way, in a
viva or interview. One file per phase, plus a master file of cross-cutting college questions.

| File | Read it when |
|---|---|
| [00-master-college-qa.md](00-master-college-qa.md) | Before any presentation. Product, novelty, gaps, moat, technology choices |
| [phase-0-foundation.md](phase-0-foundation.md) | To understand the repo, tooling, documentation and decisions |
| [phase-1-engine-cli.md](phase-1-engine-cli.md) | To understand the engine, algorithms, security design and tests |
| [phase-2-web-platform.md](phase-2-web-platform.md) | Created while building Phase 2 |
| [phase-3-hardening-release.md](phase-3-hardening-release.md) | Created while building Phase 3 |

How to study: read the "What, why, where" tables first, then open the named file and read the code for that
concept (every concept names its file). Then answer the question bank out loud without looking.

Rules for these files: facts only about what exists in the repository, honest limits, no invented numbers.
Each phase's learning file is updated at the end of that phase (the phase prompt asks for it).
