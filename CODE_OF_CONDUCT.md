# Code of conduct

We want participation in this project to be respectful, harassment-free, and productive.

Expected behavior: be kind, assume good intent, give and accept constructive feedback, and focus on
what is best for the project and the people using it.

Unacceptable behavior: harassment, discrimination, personal attacks, doxxing, sexualized language,
and sustained disruption of discussions.

Maintainers may remove comments, commits, issues, or contributors that violate this code. Report
concerns privately to the maintainer through GitHub private contact on the profile page.
